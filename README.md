# LearnVerse - Online Learning Platform

🌟 **Live Demo:** https://chikkududivya2005.github.io/learning-platform/

LearnVerse is a complete Online Learning Platform built as part of FSJ Full Stack Java Internship at Unified Mentor.

## 🎯 Project Overview
A frontend-focused Learning Management System (LMS) similar to Udemy/Coursera. Simulates real e-learning with course listing, enrollment, progress tracking, and certificates.

## ✨ Features - All 5 Phases Covered

### Phase 1 & 2: Core Pages
- Homepage with 3 featured courses
- 12 Courses listing (Java, Web Dev, Python, Data Science)
- Course details: title, description, duration, instructor, rating, lessons
- Individual course detail modal with lesson preview
- Search + Category filter + Duration filter

### Phase 3: Enrollment System
- Enroll button adds course to My Courses
- My Learning Dashboard
- LocalStorage persistence
- Enrolled count badge

### Phase 4: Progress Tracking
- Lesson player UI (ready for Spring MVC + Video.js integration)
- Lesson checklist - mark complete with checkbox
- Progress bar with % calculation (e.g., 3/5 = 60%)
- Auto certificate button after 100% completion
- Certificate with name, course, instructor, date, ID

### Phase 5: Enhancements
- Mock Login/Signup (LocalStorage)
- Fully Responsive (mobile + desktop)
- Admin Panel - Add/Delete courses
- Toast notifications
- Modern UI with gradients

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend Ready:** Java, Spring MVC, JDBC/MySQL (structure ready)
- **Storage:** LocalStorage API
- **Optional:** Video integration placeholder

## 📂 Files
- `index.html` - Main structure
- `style.css` - Styling & Responsive
- `script.js` - All logic with mock data

## 🚀 How to Run
1. Clone repo
2. Open `index.html` in browser
3. No server needed - works offline!
